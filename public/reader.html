A clear path from page to text.

  1. Upload an image or PDF. Use synthetic data for the hackathon demo. PDFs are limited to 20 pages by default.
  2. Choose recognition settings. Automatic and Mixed use Bengali + English models in browser mode; this is not script detection or translation.
  3. Extract, then review. Navigate pages; inspect uncertain regions using Review marks. Marks use engine confidence below 60 and do not declare text incorrect.
  4. Copy or download. TXT includes all page boundaries and your edits. Unprocessed pages are clearly marked. Text is not saved after refresh.

Handwritten Bangla

Tesseract is a printed-text engine. The Browser AI option downloads Qwen3.5-2B and runs it on compatible WebGPU hardware without an API account. Its Bengali land-paper accuracy is unverified. Select a small area and review every digit. The downloadable backend also supports a stronger self-hosted Qwen model. See the no-account setup guide. The self-hosted option requires a running model server. It also includes an optional Google Vision adapter; its Bengali handwriting support is experimental and has not been tested here. The Google adapter requires a server-side API key, billing and explicit sharing consent. Browser AI requires none of those.

Preprocessing and PDF limits

The preview remains the original page; review boxes are hidden when preprocessing changes geometry. A PDF containing images may be OCRed even if it has some selectable text. Force OCR is available for broken text layers. Table structure and reading order are approximate; review them manually. TIFF is supported by the Python backend only.

No legal verification, document analysis or translation is performed. Source files and text are held temporarily for processing. Queue handwriting areas in their reading order; selected areas exclude everything outside them. Use the review checkbox only after checking the original. Export before resetting or closing.
