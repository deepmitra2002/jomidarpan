Browser handwriting AI

এখন ব্রাউজারেই মডেল চালানোর ব্যবস্থা আছে। Google অ্যাকাউন্ট বা API key লাগে না। প্রথমবার মডেল ডাউনলোড করতে হবে এবং কম্পিউটারে উপযুক্ত GPU থাকতে হবে।

  1. Open the app and select Handwritten Bangla land paper.
  2. Choose Browser AI · Qwen3.5-2B.
  3. Use Select area (optionally Queue area and repeat in reading order) and drag around a few handwritten lines.
  4. Check the model-download box, then select Extract text. The first download is about 2.2 GB; progress shows each file.
  5. Review the result against the original. This is experimental transcription and may invent or omit characters and digits.

The app runs the ONNX model in a dedicated WebGPU worker. It downloads public model files from Hugging Face and runtime files from jsDelivr; document pixels are processed on your device. Browser caching may retain model files, but the app does not persist your documents or transcriptions.

Hardware and limits

Use a recent Chrome or Edge with hardware acceleration. WebGPU, shader-f16 support and sufficient GPU memory are required. Unsupported hardware, blocked downloads or insufficient memory produce an error; Tesseract is never substituted. Full browser/GPU testing was not available in the build environment. Run a small region first. Model availability is not a guarantee of Bengali handwriting accuracy.

Optional: stronger self-hosted model

The instructions below are for a separate Qwen3.5-9B server. They are not required for the browser engine.

1. Download the app

এই পুনর্নির্মিত সংস্করণে ব্রাউজারের OCR ব্যবহার করুন। পুরোনো Python backend এই সাইটে সংযুক্ত নেই।. Extract it. You need a Linux machine with a suitable GPU to run the example Qwen model. This is not a lightweight browser download. Model files and compatible drivers are required; compute may cost money even though no cloud API account is required.

2. Start the model on your GPU machine

Use a separate Python environment for the model server. Consult the official model card for current requirements.

python3 -m venv model-env
. model-env/bin/activate
pip install uv
uv pip install vllm --torch-backend=auto --extra-index-url https://wheels.vllm.ai/nightly
vllm serve Qwen/Qwen3.5-9B \
  --host 127.0.0.1 --port 8001 \
  --max-model-len 16384 --max-num-seqs 1 --reasoning-parser qwen3

3. Run the OCR app on the same machine

In another terminal, inside the extracted source folder:

python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export LOCAL_VLM_BASE_URL=http://127.0.0.1:8001/v1
export LOCAL_VLM_MODEL=Qwen/Qwen3.5-9B
export TESSDATA_PREFIX="$PWD/dist/vendor"
export OCR_TIMEOUT_SECONDS=180
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000. Once the model is reachable, the self-hosted engine appears in the selector. Choose Handwritten Bangla land paper. The public demo link cannot access this local backend automatically. For a remote GPU machine, forward app port 8000 through SSH and open that forwarded local address.

4. Transcribe, then verify

Upload a clear image. The model is instructed to preserve script, names, numerals, measurements and line breaks, and mark unreadable spans as [অস্পষ্ট]. These instructions cannot guarantee accuracy: a vision model can invent or omit text. Compare every field with the source. No confidence percentage or legal verification is provided.

For dense or damaged pages, crop into readable sections before uploading. No automatic page segmentation is implemented. Do not treat empty output, a plausible-looking number, or a model uncertainty marker as proof of correctness.

If you do not have a GPU server

Try the experimental browser model above if your computer supports WebGPU. The 9B server remains optional; this app cannot supply a GPU server. Collect a few consented, redacted sample pages and ground-truth transcriptions before choosing a hosted model or paying for compute.
